# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

顶部菜单「超差盘点台」进入时段盘点整页：上块选小时窗（当前小时 / 最近 4 小时 / 最近 24 小时或自定义起止），中块列该窗入队量、合格量、超差量与超差占比，下块放刷新与口径说明。所有数字由服务端按任务创建（入队）时刻聚合（`GET /api/audit/summary?start=&end=`），待处理未结案行不计入合格或超差；超差占比 = 超差量 ÷（合格量 + 超差量），无已结案行时显示「—」。校准员可改看窗宽度，巡检员只读不能改窗。

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理再出超差。
3. inspector 不能提交。
4. 连交三笔故意超差样条，再交一笔压线合格样条（偏差恰为允差 0.08 nm）；进入「超差盘点台」打开当前小时窗，超差占比抬高且合格量至少为一。
5. 把窗改窄到不含刚才那批时刻，超差占比回落或变空。
6. calibrator 与 inspector 都能进盘点台，但只有 calibrator 能改窗口宽度。
