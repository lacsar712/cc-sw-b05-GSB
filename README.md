# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3195 |
| 接口 | http://localhost:8195 |
| PostgreSQL | localhost:54395 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| calibrator | calib123456 | 可提交校准 |
| inspector | insp123456 | 只看 |

## 启动

```bash
cd projects/16-spectrum-wavelength-desk
docker compose up --build
```

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理再出超差。
3. inspector 不能提交。
4. 菜单进「超差盘点」整页台：上块选小时窗，中块列该窗入队量 / 合格量 / 超差量 / 超差占比，下块放刷新与口径说明。数字一律由服务端按创建入队时刻聚合，待处理行不进合格或超差桶。
5. 连交三笔故意超差样条再交一笔压线合格样条，打开当前小时窗：超差占比抬高且合格量至少为一；把窗改窄到不含那批时刻，占比回落或变空。
6. 可写与只读会话均可进入盘点台，但只有校准员能改窗，巡检员只能看。
